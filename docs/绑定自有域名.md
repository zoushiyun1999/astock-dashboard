# 绑定自有域名到看板

> 目标：把 `https://zoushiyun1999.github.io/astock-dashboard/`
> 变成 `https://asx.你的域名.com/`
> 好处：以后换任何托管商，网址都不变 —— 这才是真正的「链接永不丢失」。

**为什么建议用子域名（如 `asx.` 前缀）**：根域名保持干净，以后想放别的东西互不干扰；
万一要解绑，删掉一条记录即可，不影响其他服务。

---

## 准备：确认三件事

1. 域名已**实名认证**（国内注册商必需，否则解析会被拦截）
2. 能登录域名管理后台（腾讯云 / 阿里云 / 华为云 / 万网等）
3. 想好用什么前缀，本文以 `asx` 为例 → 最终网址 `https://asx.你的域名.com/`

---

## 第 1 步：在 GitHub 填域名

1. 打开 https://github.com/zoushiyun1999/astock-dashboard/settings/pages
2. 找到 **Custom domain**，填入：`asx.你的域名.com`（**不要带 http:// 和结尾斜杠**）
3. 点 **Save**
4. 下方 **Enforce HTTPS** 先别勾（等证书签发好再勾，通常等 10 分钟到 1 小时）

> 保存后 GitHub 会去做 DNS 检查，此刻大概率报错提示解析不对 —— **这是正常的**，因为你还没配解析。继续第 2 步。

---

## 第 2 步：去域名后台加解析记录

登录你的域名管理后台 → 找到 **DNS 解析 / 域名解析** → **添加记录**，加两条：

### 记录一（主记录，必加）

| 字段 | 填写内容 |
|---|---|
| 记录类型 | **CNAME** |
| 主机记录 | **asx** ←（如果你要的是 `asx.你的域名.com`） |
| 解析线路 | 默认 |
| 记录值 | **zoushiyun1999.github.io** ←（注意：**结尾不能加斜杠，也不带 /astock-dashboard**） |
| TTL | 600（10 分钟）或默认 |

### 记录二（防验证冲突，建议加）

| 字段 | 填写内容 |
|---|---|
| 记录类型 | **TXT** |
| 主机记录 | **_github-pages-challenge-zoushiyun1999.asx** |
| 记录值 | 在 GitHub Custom domain 下方那串 `_github-pages-challenge-...` 的验证码（点开可以看到一长串字母数字） |

> 第二条的作用：向 GitHub 证明这个域名是你的。**如果主机记录填不进去（有些平台不允许这么长的前缀），可以跳过**，只做记录一也能成。

---

## 第 3 步：等生效并勾选 HTTPS

1. 等 **10 分钟 ~ 2 小时**（DNS 生效时间，取决于 TTL）
2. 回到 https://github.com/zoushiyun1999.github.io/astock-dashboard/settings/pages
3. 刷新页面，看 Custom domain 下方的状态：
   - 显示绿勾 **DNS check successful** → 继续
   - 仍是红叉 → 等一会儿再刷，或看下面的排错表
4. 勾选 **Enforce HTTPS**（强制加密），等证书签发完成后才能勾

---

## 第 4 步：我帮你收尾

域名生效后告诉我，我会：

1. 更新 `config/site.json` 的 `siteUrl` 为你的新域名，`fallbackUrl` 保留 GitHub 官方地址
2. 同步更新 GitHub 仓库的 `SITE_URL` / `FALLBACK_URL` 变量
3. 跑一次体检，确认域名可达、内容正确
4. 微信推送里的看板链接自动换成新域名

---

## 排错对照表

| 现象 | 原因 | 处理 |
|---|---|---|
| GitHub 一直报 DNS 检查失败 | 记录值写错（加了 `https://` 或结尾斜杠） | 值必须是纯 `zoushiyun1999.github.io` |
| 记录加不进去，提示"已有 CNAME" | 该主机记录已存在别的记录 | 先删掉旧的 `asx` 记录再加 |
| 浏览器打开显示 GitHub 404 页 | 域名已生效但 Pages 未绑定 | 回第 1 步确认 Custom domain 已保存 |
| 打开显示"不安全"，无锁标 | HTTPS 证书还没签发 | 等 1 小时，或在 Pages 页面重新点一次 Save 触发签发 |
| 打开是旧的别的网站 | DNS 缓存 | 换手机流量试，或等 TTL 到期 |
| 域名注册商提示"未实名" | 国内域名实名要求 | 去注册商完成实名认证，通常 1-3 天 |

---

## 顺带一提：要不要同时配国内镜像

如果你发现 `github.io` 在手机上打开**偏慢或偶尔打不开**，可以再叠加一个国内静态托管（腾讯云 EdgeOne Pages / Cloudflare Pages，都免费、都有固定域名），然后把域名改指向镜像。

**关键好处**：因为域名在你手上，换托管商**只需要改一条 DNS 记录，网址一个字都不变** —— 这正是当初做这件事的意义。

具体做法等你说了算，现在不必做。
