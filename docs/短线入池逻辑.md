## 一、整体流程

```
湖南人复盘（AI读图+文字）+ 行鱼复盘（AI读图+文字）
        ↓
① 提炼当日主线板块（短线逻辑，4-8 个）
        ↓
② 每个板块写推导链：空间标杆 → 趋势中军 → 低位补涨
        ↓
③ 按规则筛选 8-12 只个股进池（watchlist）
        ↓
④ 每只股用 group 字段挂到某个板块
        ↓
⑤ 前端按板块分组渲染：一张卡片 = 思路 + 个股
```

**核心原则**：思路和个股必须在同一张卡片里。个股不能脱离板块存在——如果某只强势股找不到归属板块，要为它**新建一个板块条目**。

---

## 二、板块逻辑链规则（短线逻辑）

每天先确定 4-8 个主线板块，按强度排序。每个板块一条，四个字段：

| 字段       | 含义    | 要求                               |
| -------- | ----- | -------------------------------- |
| `sector` | 板块名   | 与 watchlist 的 `group` **必须完全一致** |
| `stage`  | 所处阶段  | 2-6 字，见下方词表                      |
| `why`    | 为什么热  | 1-2 句，写催化事件/政策/订单/消息             |
| `chain`  | 个股推导链 | 80-150 字，用「→」连接推导步骤              |

**stage（阶段）词表**：

`启动确认` / `主升加剧` / `情绪发酵` / `事件驱动` / `尾盘发力` / `轮动补涨` / `分歧退潮`

**chain 的写法模板**：

```
{空间标杆}（板数最高，常提示"位置高未入池/仅作情绪风向标"）
→ {趋势中军}（订单或业绩实锤 → 入池）
→ {低位补涨}（入池博卡位）
→ 为什么不选其他（如"纯轮动脉冲未入池"）
```

**必须写清楚两件事**：

1. 入池的个股，为什么选它
2. 没入池的强势股，为什么不选（位置过高 / 纯轮动 / 身位分散 / 擦边概念）

## 三、个股入池规则（watchlist）

### 选股范围

来自当日复盘提炼的**连板梯队 + 板块热点**。

### 数量

**8-12 只**（当前值）。

### 优先级（当前规则）

| 顺序 | 规则                    | role 写法      |
| -- | --------------------- | ------------ |
| 1  | 全市场最高连板股              | `N板·最高标`     |
| 2  | 次高板依次往下               | `N板`（如 `3板`） |
| 3  | 各板块热点排名第一的龙头          | 同上           |
| 4  | 不足 8 只时，从板块热点按排名补充核心股 | 首板写 `首板`     |

### 排序

按**板数从高到低**（首板垫底）。

### 字段结构

```json
{
  "name": "海鸥股份",
  "group": "液冷/算力硬件",
  "role": "3板",
  "sector": "液冷",
  "note": "液冷服务器核心，CDU订单排至2026年底"
}
```

| 字段       | 说明                                         |
| -------- | ------------------------------------------ |
| `name`   | 股票名                                        |
| `group`  | **所属板块名，必须与短线逻辑的 `sector` 一致**（前端靠它归类）     |
| `role`   | 板数身份：`N板·最高标` / `N板` / `首板`                |
| `sector` | 细分公司属性（液冷/CPO/地产/券商/农业种业/AI应用），比 group 更具体 |
| `note`   | 一句话：题材、催化逻辑或盘中状态（如"一字加速""盘中分歧后回封"）         |

## 四、前端渲染方式

**位置**：看板第三个 Tab「📌 短线关注」  
**代码**：`dashboard/js/app.js` → `renderWatchlist()` / `pickCard()` / `stockLi()`

每张板块卡片结构：

```
┌──────────────────────────────────────┐
│ ① 液冷/算力硬件 [主升加剧]    入池3只 │
│                                       │
│ 为什么热：AI芯片功耗1000W→液冷必选项… │
│ 个股推导：康盛股份位置高未入池 → 海鸥 │
│           股份3板趋势中军 → 入池…     │
│ ─────────────────────────────────── │
│ 1 海鸥股份 [3板] 液冷                │  ← 白底内嵌列表
│   液冷服务器核心，订单排至2026年底    │
│ 2 星网锐捷 [3板] CPO/算力            │
│ 3 金帝股份 [2板] 液冷                │
└──────────────────────────────────────┘
```

**特殊情况处理**：

- 板块无个股入池 → 显示「该板块当日无个股入池」（配合 chain 里的原因说明）
- 个股的 `group` 匹配不到板块 → 兜底归入末尾「其他强势股」
- 完全没有板块数据 → 兜底按板数平铺列表

## 六、可调参数清单

| #  | 参数          | 当前值                | 改法                                              |
| -- | ----------- | ------------------ | ----------------------------------------------- |
| 1  | 入池数量        | 8-12 只             | 改任务 prompt「短线逻辑 + watchlist 联动规则」第 3 条          |
| 2  | 选股优先级       | 最高标 → 次高板 → 板块龙头   | 同上第 4 条                                         |
| 3  | 排序方式        | 板数从高到低             | 同上第 4 条（可改为按板块分组内排序）                            |
| 4  | 板块数量        | 4-8 个              | 同上第 1 条                                         |
| 5  | 推导链字数       | 80-150 字           | 同上第 2 条 chain                                   |
| 6  | 阶段词表        | 7 个固定词             | 同上第 2 条 stage                                   |
| 7  | role 命名     | `N板·最高标`/`N板`/`首板` | 同上第 3 条                                         |
| 8  | 是否允许"无入池板块" | 允许（显示提示）           | 同上第 4 条                                         |
| 9  | 卡片配色/排版     | 紫卡片 + 白底列表         | 改 `css/style.css` 的 `.pick-card` / `.pick-list` |
| 10 | 卡片信息顺序      | 板块名→为什么热→推导→个股     | 改 `js/app.js` 的 `pickCard()`                    |

**改动生效方式**：

- 参数 1-8 → 改晚报定时任务 prompt（当天 21:00 生效）
- 参数 9-10 → 改前端代码 + 手动部署（立即生效）
- 改完历史数据也想变 → 需同时改 `dashboard/data.js` 里的 `短线逻辑` 和 `watchlist`

## 七、几个常见的调整方向（供参考）

- **只要龙头、不要补涨**：把优先级第 4 条"不足 8 只时补充核心股"删掉，改为"只取各板块第一龙头"
- **控制风险**：新增规则——累计涨幅超 50% 或 5 板以上的，note 里必须写明"高位风险"
- **池子更聚焦**：数量改为 6-8 只，只保留最强的 2-3 个板块
- **加成交额/换手门槛**：需要复盘数据里有这些字段，目前湖南人复盘图里通常有成交额，可以加规则但会受限于识别准确度
