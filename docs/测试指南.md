# 🧪 测试指南

> 在这个板块的对话里说下面的话，就能手动测试对应功能。

---

## 1. 测试早报（完整流程）

**对话指令**：「测试一下早报」

执行过程：
1. 抓取韭研公社「开盘必读」主页 → 找最新一篇帖子
2. 判断是否今天发布（今天没发布则提示，不会更新）
3. 打开文章页 → 提炼要闻、人气股、公告、新股
4. 更新网页看板数据 → 部署云端 → 微信通知「已更新」

**只看不推**：「测试早报，但不要更新看板，直接给我看内容」

## 2. 测试晚报（完整流程）

**对话指令**：「测试一下晚报」

执行过程：
1. 抓取淘股吧「湖南人」「行鱼复盘」两个博客 + 韭研公社投资日历
2. 分别判断今天是否发布了复盘帖（没发则跳过该博主）
3. 打开今天发布的主帖 → 提炼摘要
4. 更新网页看板数据 → 部署云端 → 微信通知「已更新」

## 3. 测试单个来源

- 「测试一下湖南人能不能抓到」→ 只测湖南人
- 「测试一下韭研公社开盘必读」→ 只测早报源
- 「今天开盘必读发了没」→ 只查最新帖状态，不推送

## 4. 检查推送记录

- 「今天推送了吗」→ 查看今天推送情况
- 「看看日志」→ 查看 logs/ 目录下的推送记录

## 5. 测试网页看板

网页看板位于 `../dashboard/index.html`，数据文件 `../dashboard/data.js`。

- **电脑预览**：直接双击 `dashboard/index.html`（数据内嵌在 data.js，无需服务器）
- **「测试一下看板」**：用当前最新抓取结果重新渲染一次网页数据（更新 data.js）
- **「部署网页看板」**：把 `dashboard/` 部署到云端静态托管，获得手机可访问的公网链接
- **「看板加 XX 板块」**：调整网页展示结构（需同步修改 automation prompt 和 index.html）

> 注意：手动测试早报/晚报时，如果只说"测试"，默认只更新网页看板；**想同时发微信通知，说"测试并通知微信"**。

---

## ⚠️ 测试注意事项

1. **周末/节假日**：数据源当天不更新，测试会提示"今天无更新"，这是正常现象，不是故障。
2. **湖南人复盘**：正文是图片，测试结果会显示标题+摘要+链接，属预期行为。
3. **时间敏感**：早报源通常在 7:30–8:10 更新，早上 8:30 前测试可能拿到的是昨天的内容；晚报源 20:00 后才齐，白天测试只能拿到昨天或早前的内容。**想测最新内容，建议在源更新时间之后测试。**
4. **更新提醒**：测试更新看板后若部署成功，会发一条微信通知提醒「已更新」，属预期行为；如不想打扰，说"只看不推"。

每次推送建议把时间、内容概要记录到 `logs/YYYY-MM-DD.md`，方便日后回溯。
