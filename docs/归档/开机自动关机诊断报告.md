# 「开机就自动关机」诊断报告

诊断时间：2026-09-11 18:07
主机：DESKTOP-NQT2JG0 / ASUS PRIME A520M-K + R5 5600 / Win10 19045

---

## 结论：不是硬件故障，是 QClaw 执行了休眠命令

电脑没有关机，是**被休眠（hibernate）了**。休眠时屏幕全黑、风扇停转、电源灯可能仍亮或灭，**外观与关机几乎无法区分**，这是你判断为"自动关机"的直接原因。

下令者是 **QClaw**（通过微信通道接入的 AI Agent）。

---

## 完整触发链路

```
你在微信里发送「休眠」
   ↓
QClaw 微信通道接收（openclaw-weixin）
   ↓
AI 判定为休眠请求
   ↓
执行命令：shutdown /h
   ↓
Windows 进入休眠
```

**为什么开机后又立刻"关机"**：QClaw 随开机自启动，启动后把通道里**积压的「休眠」消息逐条补执行**，于是电脑刚唤醒就再次休眠，形成循环。

## 安全隐患（需要你重视）

`C:\Users\zoush\.qclaw\openclaw.json` 中配置为：

```json
"channels": {
  "openclaw-weixin": {
    "enabled": true,
    "allowFrom": ["*"]
  }
}
```

`allowFrom: ["*"]` 表示**不限制来源**。这意味着：

- 任何能给这个微信机器人发消息的人，都能驱使你的电脑执行命令
- 可执行范围不只是休眠，还包括**关机、删文件、运行任意程序**
- 配合"开机自启"，攻击者可让电脑反复休眠/唤醒，甚至造成数据损坏

**这是比"自动关机"本身更严重的问题。**

---

## 解决方案（按推荐度排序）

### 方案 A：直接关闭 QClaw 微信通道（推荐）

理由：你此前已决定弃用整套自动化系统，这个通道目前只剩风险，没有用途。

操作：
1. 打开 `C:\Users\zoush\.qclaw\openclaw.json`
2. 把 `"openclaw-weixin"` 的 `"enabled": true` 改为 `false`
3. 保存后重启 QClaw

效果：立即切断外部指令入口，休眠/关机循环终止。

### 方案 B：保留通道，但收紧白名单

理由：如果你还想偶尔用微信控制电脑。

操作：把 `"allowFrom": ["*"]` 改为只允许你自己的账号 ID。

效果：保留便利性，但需先确认自己的微信 openid（在 QClaw 会话记录里可查），配置略麻烦。

### 方案 C：取消 QClaw 开机自启

理由：治标，不治本——通道仍在，手动打开后问题复现。

操作：
1. `Win + R` 输入 `taskschd.msc`，或直接改注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`
2. 删除 `com.tencent.qclaw` 这一项
3. 另有 `OpenClawTray`（`D:\OpenClawTray\OpenClaw.Tray.WinUI.exe`）建议一并移除
