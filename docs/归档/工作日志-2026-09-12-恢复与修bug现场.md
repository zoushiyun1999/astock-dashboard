### 图片压缩的通用结论（跨项目可复用）

**给「扁平色块 + 文字」的长图做无损感压缩，调色板量化 PNG 优于 WebP。** 实测数据：

| 方案 | 2008×20640 | 2008×23960 |
|---|---|---|
| 原始 PNG | 4.91MB | 5.86MB |
| **原尺寸 + 量化256色 + PNG** | **1.86MB** | **2.20MB** ✅ |
| 缩至16383高 + WebP q85 | 2.22MB | 2.26MB |

两个反直觉点，下次少走弯路：
1. **WebP 单边硬上限 16383px**（超高长图必须先缩放才能编码）
2. **缩放反而让压缩率变差**：LANCZOS 插值制造大量中间色，量化后更难压
   （1594×16383 = 2.89MB > 原尺寸 1.86MB）→ 结论是**能不缩放就不缩放**

## 第四轮：最终 bug 排查

用户要求「最后检查一下还有什么 bug 或者不合理的地方」。

### 查出的最严重问题：**读-改-写 data.js 的脚本会静默清空全部历史**

`verify.js` 与 `screener.js` 都用 `try { eval(readFileSync(data.js)) } catch (e) {}`
然后无条件写回 —— data.js 一有语法错误，`data` 退化成空结构被写回，7 天历史全没。

**这是一个可以推广的模式识别**：只要看到
```js
try { X = parse(file) } catch (e) { /* 空 */ }
...
writeFileSync(file, serialize(X))
```
就是"解析失败 → 静默清空"的定时炸弹。凡"读-改-写"同一个文件的地方都要检查这一点。

正确的三层防线（本次采用的模式，可直接复用）：
1. **解析失败即中止**（绝不降级成默认值）
2. **规模骤减拦截**（新数据的条目数低于旧的一半就拒绝写回）
3. **乐观锁**（写回前重读文件，与读取时刻原文逐字节比对，不一致说明有并发写 → 中止）

### 修安全阀代码时的两个坑（都是测试才发现的）

1. **基线必须存"数字快照"而不是对象引用**：`saveDataSafe(file, next, prevData, src)` 里
   如果 `next === prevData`（同一个对象），调用方就地修改会连带改掉基线，"骤减"检查永远不触发。
   正确做法是在读取时把 `reports.length` / `calendar.length` 存成数字传下去。
2. **中止不要用 `process.exit(1)`**：Windows 下管道输出是异步的，直接退出会把刚打印的报错截断。
   改成 `throw` 一个带标记的 Error，顶层 `.catch()` 统一打印 + 设 `process.exitCode = 1`。

> 核心教训：**"防事故"的代码必须构造故障场景实测**。这类代码平时不执行，
> 引用别名、输出截断这种问题读代码根本看不出来 —— 本次两个缺陷都是写测试时暴露的。

### 可复用手法：从 IIFE 里「按大括号配对抽出函数」做无浏览器单测

浏览器端代码躲在 IIFE 里、又依赖 DOM/时间，通常没法直接单测。这次的做法：

1. 读 `app.js` 源码，用**大括号配对扫描**把目标函数原文切出来
   （`function name(` 定位起点 → 从第一个 `{` 开始数深度 → 深度归零处结束）。
   抽出失败直接抛错，避免"测试静默通过但什么都没测"。
2. 把切出来的函数原文 + 相关常量，一起 `vm.runInContext` 到一个**假环境**里：
   假 `Date`（无参构造返回指定的"现在"，`prototype` 指向真 Date.prototype 以保留 padStart 等方法）、
   假 `document.getElementById`、假 `localStorage`。
3. 用真日期算出的 mock 时间点跑断言。

**为什么必须这样测**：这些判定全是时间相关的，而**周末无法用真实页面触发** ——
`isTradingToday()` 返回 false 会直接短路成"休市"，怎么点都测不到目标分支。
不构造假时间就只能读代码猜，而上一轮就是这么漏掉两个每天触发的 bug 的。

> 桩的坑：`document.getElementById` 的假元素要按真实用法补齐字段 —— 至少
> `className` / `innerHTML` / `textContent` / `style` / `classList.toggle`。
> 第一版漏了 `classList`，`updateEveningDot()` 一跑就 TypeError。
