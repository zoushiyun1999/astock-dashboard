## 【重大】排查"开机就自动关机"——根因是 QClaw 执行 shutdown /h

用户报告：电脑一开机就立刻自动关机。

### 结论：不是硬件故障，是 QClaw 按微信指令休眠了电脑

**完整链路**：
```
你在微信发「休眠」
  → QClaw（channels.openclaw-weixin 通道）
    → AI 判定为休眠请求
      → exec: shutdown /h
        → 系统进入休眠（hibernate）
```

### 决定性证据

1. **System 日志事件 ID 187**（今天 3 次：15:26:31、18:02:34、18:03:29）
   - `ApiCallerName = \Device\HarddiskVolume3\Windows\System32\shutdown.exe`
   - `SystemAction = 3`
2. **事件 ID 42**：`TargetState=5`（休眠）、`Reason=4`（Application API）
3. **QClaw 会话轨迹** `00b1f744-adec-42d2-9042-b17eb8e2076a.trajectory.jsonl`：
   - `toolMetas: [{"toolName":"exec","meta":"shutdown /h"}]`
   - 多条 user 消息内容就是「休眠」，AI 回复"⚠️ 即将执行休眠 — 电脑将在 3 秒后进入休眠状态"
   - 会话中还夹着「关机」"电脑状态"`powercfg /availablesleepstates` 等指令
   - 用户 09-10 17:30 还要求过"以后执行休眠之前，先给我发一条信息告知"

### 为什么"开机后立刻又关机"

- QClaw 随开机自启：注册表 Run 项 `com.tencent.qclaw = D:\QClaw\v0.2.37.630\QClaw.exe --auto-launch`，另有 `OpenClawTray`
- 15:26:31 进入休眠 → **18:01 才唤醒**（休眠 2h35m）→ 18:02、18:03 又连发两次
- 开机后积压的「休眠」消息被逐条补执行，形成"刚开机就关机"的观感

### 已排除的硬件问题

- 今日**无** Kernel-Power 41 / EventLog 6008 意外关机
- **无** WHEA-Logger 硬件错误
- 磁盘 SMART Healthy；唯一 minidump 是 09-09 10:47 的 `0x0000013A`，与本次无关
- 电源超时设为"从不"，排除定时睡眠

### 安全隐患（重要）

`~/.qclaw/openclaw.json` 中：
```json
"channels": { "openclaw-weixin": { "enabled": true, "allowFrom": ["*"] } }
```
`allowFrom: ["*"]` 意味着 **任何人都能通过微信驱使本机执行命令**（含关机/休眠/任意 exec）。已建议用户切断该通道。
