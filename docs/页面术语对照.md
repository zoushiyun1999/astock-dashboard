# 看板页面术语对照

> 本文档配合 `页面术语对照.svg`（页面结构解剖图）使用，方便提需求时精准对齐。
> 看板链接：见 `config/site.json` 的 `siteUrl`（唯一事实源，勿在此硬编码）

## 页面骨架（从上到下）

| 名词 | 英文 | 说明 |
|---|---|---|
| 页头 | Header | 顶部蓝色区域，装 logo、标题、日期、状态区 |
| Logo | Logo | 蓝色小方块里的「A」，品牌图形标志 |
| 标题 | Title | Logo 旁边的「股速览」 |
| 日期 | Date | 标题下方的当天日期（如「9月4日 · 周四」） |
| 状态区 | Status | 右上角几行「早报 8:30 · 晚报 21:00 · 量价 14:30 · 投资日历 8/30」，按数据源展示各自时间与状态 |
| 健康条 | Health bar | 绿色「各源运行正常」条，一眼判断系统是否异常；节假日显示「今日休市」 |
| 标签页 | Tab | 五个板块切换：早报 / 晚报 / 短线关注 / 投资日历 / 量价选股 |
| 下划线指示器 | Active indicator | Tab 下方蓝色短横线，标出当前在哪个 Tab（有滑动动画） |

## 内容区

| 名词 | 英文 | 说明 |
|---|---|---|
| 卡片 | Card | 每个白色圆角块，如「明日关注 · 液冷算力」 |
| 分区标题 | Section title | 卡片左侧色条 + 标题（如「明日关注」） |
| 徽章 / 标签 | Badge / Tag | 股票名后的小标签，如「+3.2%」「-1.1%」「算力/AI」 |
| 表格 | Table | 量价选股里「名称/涨幅/换手/量比」的格子 |
| 空状态 | Empty state | 无数据时的「待更新」提示 |

## 底部

| 名词 | 英文 | 说明 |
|---|---|---|
| 页脚 | Footer | 底部「更新：早报 8:32 · 晚报 21:05 …」按源展示时间 |

## 交互类（不可见，但一直在用）

| 名词 | 英文 | 说明 |
|---|---|---|
| 日期导航 | Pager | 顶部「← 前一天 / 后一天 →」切换早报/晚报日期 |
| 轮询 | Polling | 每 60 秒自动检查一次是否有新数据 |
| 持久化 | Persistence | 刷新后记住当前 Tab 与滚动位置（localStorage） |
| 响应式 | Responsive | 同一页面在手机/平板/电脑自动调整布局 |

## 配色约定（重要）

- **涨 = 红色，跌 = 绿色**（A股习惯，与国际相反）。
- 状态圆点：绿 = 已生成、灰 = 待更新、红 = 未更新、蓝 = 休市/信息。
