四、为什么会这样

  • 选股逻辑天然是"追高"：入池规则是"最高连板 → 次高板 → 板块龙头"，也就是只选当天已经涨停的强势股。这类票次日往往高开，赚钱的要么一字板买不进，要么已经在高位。
  • 能买到的≈分歧转弱：一字板（开=高=低=收）实盘竞价买不进，9 条被剔除后收益从 +0.22% 降到 -0.22%——说明真正贡献正收益的恰是买不进的那些。
  • 早报更差：早报基于"人气榜 + 公告"，而人气榜本身就是滞后指标（已被市场充分定价），-1.17% 符合直觉。
  • 样本期太短：只有 5 个交易日，且恰逢情绪退潮（9/4 集泰股份 -9.99%、飞龙 -7.57%），单期数据不足以定性，但"扣费后打平或微亏"这个结论在短线追涨策略上是稳定的。

五、建议（按优先级）

#动作说明
1代码反查校验推荐输出必须带 code，且用行情接口反查名称做一致性校验；不匹配就丢弃或标红。可一次性消灭"代码错配 + 幻觉股名"两类问题。
2修 9/7 晚报触发时点晚报被提前到盘前触发会永远抓不到当日复盘。建议加"运行时段守卫"：不在 15:00 之后就跳过 evening 生成。
3量价选股按日期归档screener 改成数组（保留最近 N 期），否则永远无法验证策略有效性。
4解决早报延迟PC 关机/休眠导致补跑。二选一：设置 Windows 永不睡眠（仅关屏），或迁移到 GitHub Actions 云端执行。
5加"不追高"过滤若仍想用这套做买入参考，建议加规则：开盘涨幅 >5% 或一字板的不计入可交易，只作情绪风向标。回测显示这能显著改善实盘可执行性。
6看板定位调整为"观察池"当前数据不支持"买入即盈利"的预期，把它定位成盯盘/复盘工具更合适，避免误导。
