# 📊 A股推送系统

> 每天自动把分散的股票信息整合成早报/晚报/选股/验证四类简报，**输出到网页看板**（`dashboard/`，手机浏览器打开即看，排版美观、支持历史回看）。本目录是系统的**专属板块**——所有配置、说明、测试方法都在这里。
>
> ℹ️ **运行状态（2026-09-12）**：已从删除隔离区恢复，**当前运行在本地模式**（数据提交到本地 git，未配置 `.gh-token` 时云端推送自动跳过）。**微信通知功能已整体下线**。

### 🌐 A股速览网页看板

定时任务生成内容后，会把内容写入 `dashboard/data.js`，打开 `dashboard/index.html` 即可看到**排版精美的网页版**：

- 📱 **移动端优先**：手机上打开即看，卡片式排版，涨红跌绿
- **5 个 Tab**：🌅 早报 / 🌙 晚报 / ⚡ 短线 / 🔍 量价 / 📅 日历
- ⚡ **短线 Tab**：聚合视图，展示晚报推荐板块里最值得跟的个股（数据源是 `evening.明日关注`）
- 🔍 **量价 Tab**：技术面选股结果，含入选理由与命中条件
- 📅 **日历 Tab**：展示「A股投资日历」博主的月度日历**原图**+完整事件，跟随博主发帖节奏更新（不限时效）
- 📅 **历史回看**：早报/晚报保留最近 7 天，可切换日期
- 🔗 **原文直达**：每份简报附原文链接

打开方式：
- 💻 **电脑**：双击 `dashboard/index.html`
- 📱 **手机（推荐）**：云端静态托管，地址见 **`config/site.json` 的 `siteUrl`**（链接唯一事实源，禁止硬编码）。打开后点「添加到主屏幕」，之后不再依赖收藏夹
- 🔄 **自动更新**：数据更新后 push 即自动发布到云端；页面本身每分钟检查一次新数据，有新内容时底部弹出提示，点击即可更新，不用手动刷新

**网页项目结构**（已登记为独立项目，方便随时改排版/效果）：

```
dashboard/

├── data.js         # ⚠️ 定时任务自动写入，勿手改
├── screener.js     # ⚠️ 量价选股结果（定时任务写入）
```

## 二、系统架构

```
┌────────────────────────────────────────────────┐
│            定时任务（每天自动运行）                │
│   8:30 A股早报  /  21:00 A股复盘晚报             │
├────────────────────────────────────────────────┤
│  1. 抓取数据源（网页抓取 + AI读图）                │
│     · 早报：韭研公社开盘必读文章页（正文可抓）      │
│     · 晚报：淘股吧湖南人博客 → 下载图片 → AI读图   │
│             行鱼复盘文字帖 → 直接摘要              │
│     · 📅专版：韭研公社投资日历博主主页 → 下载原图   │
│               + 提取完整事件 → 写入 calendar       │
│  2. 判断"最新帖是否为今天发布"                    │
│     · 是 → 提炼摘要（早报500字 / 晚报1000字内）   │
│     · 否（周末/节假日）→ 跳过，不推送             │
│  3. 生成简报（精炼文字版，适合手机阅读）            │
│  4. 同步写入 dashboard/data.js（网页看板）          │
│  5. 发布（bash tools/publish.sh "说明"）           │
│     · 刷新前端版本号，导出 data.json/version.json  │
│     · git 提交 → post-commit 钩子自动推 GitHub     │
│       （未配置 .gh-token 时静默跳过，不影响本地）   │
│     · 有令牌时 GitHub Actions 发布到固定域名        │
│  6. 追加运行日志（logs/日期.md，含各源/发布结果）   │
└────────────────────────────────────────────────┘
```

## 五、怎么用这个板块

直接在这个板块的对话里说需求，我来执行：

### 🔧 更改配置
- 「早报改到 8:00」→ 调整推送时间
- 「晚报只要湖南人，去掉行鱼」→ 调整数据源
- 「早报再加一条美股隔夜行情」→ 扩展内容
- 「加一个雪球博主 xxx」→ 新增来源（告诉我昵称/主页链接）

### 🧪 手动测试
- 「测试一下早报」→ 立即抓取早报并更新网页看板
- 「测试一下晚报」→ 立即抓取晚报并更新网页看板
- 「只看不推」→ 只生成简报内容，不写网页、不发通知
- 详见 [docs/测试指南.md](docs/测试指南.md)

### 📜 查看记录
- 「今天推送了吗」→ 查看最近推送记录
- 每次任务运行都会在 [`logs/`](logs/) 目录追加当天日志（数据源抓取状态 / 看板写入 / 发布 / 微信通知结果），文件名为 `日期.md`
- 项目数据用 **git 管理**（`A股推送系统` 目录已初始化仓库，每次任务自动提交），data.js 万一写坏可随时回滚
- **提交会自动同步上云**：`.git/hooks/post-commit` 钩子会在每次本地提交后自动推送 GitHub，云端随即发布。
  若发现线上数据没更新，先检查这个钩子是否存在（源文件留档在 `tools/git-hooks/post-commit`）
- 手动补发布：`bash tools/publish.sh "说明"`；只看体检：`node tools/health_site.js`

### ⏸️ 暂停/恢复
- 「先暂停早报」/「恢复晚报」→ 暂停或恢复对应任务

## 六、常见问题

**Q：周末会收到推送吗？**
不会。任务会先判断最新帖发布日期是否为今天，周末/节假日源不更新就自动跳过。

**Q：湖南人复盘正文为什么能提取文字？**
他的复盘正文是图片格式，系统会先把图片逐张下载，然后用 AI 读图识别内容，再提炼成结构化的文字总结（大盘概况/连板梯队/板块热点/市场情绪）。输出为纯文字精炼版，写入网页看板，适合手机阅读。若读图失败会自动降级为标题+链接。

**Q：推送失败了怎么办？**
告诉我「检查推送」，我会查看任务状态和日志并重新推送。

**Q：网页看板在手机上怎么看？**
看板是云端静态托管（不会停机、链接固定），地址见 **`config/site.json` 的 `siteUrl`**。数据每天 8:30 / 21:00 更新后自动发布；页面每分钟自检一次，有新数据会提示更新。若打不开，改用同一文件里的 `mirrorUrl` 或 `fallbackUrl` 备用入口，并等次日 04:00 的健康检查推送告警。

**Q：网页看板的数据是实时的吗？**
不是实时行情，而是每天 8:30 / 21:00 定时任务跑完后生成的**当日总结**。打开网页看到的就是最近一次生成的结果，顶部会显示更新时间。
